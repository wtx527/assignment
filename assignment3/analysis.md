# 简答

## 1. 哪条路线对稀疏的 (s, a) 更敏感？

这份 2000 条随机轨迹里，36 个 (s, a) 都有样本，最少的是 B1 上的补糖和小剂量胰岛素，各 18 次。已访问格子上，固定步长的 Q-Learning 更敏感。\(\alpha = 0.5\) 让新目标占一半权重，所以前 500 条会把 B9 从大剂量改成小剂量，前 1000 条又把 B8 改成小剂量；计数模型两处都保持大剂量。把步长改成 \(1/N(s,a)\) 之后，500 条起就和模型的动作表相同，说明翻转来自步长，不是目标函数不同。完全没访问过的格子会反过来：模型把转移写成均匀、奖励写成 0，规划会把这个填出来的模型当成真的；这份预算里没有这样的格子。

## 2. 一个策略不一致的状态

完整 2000 条上，九个状态的贪心动作相同。不一致出现在同一条数据的前缀里：只用前 1000 条时，B8 的模型策略是 i2，Q-Learning 是 i1。计数模型给出的动作价值大约是 i2 为 \(-3.56\)、i1 为 \(-5.75\)，大剂量更常落到 B6 和 B7。此时 Q 表是 i1 约 \(-2.29\)、i2 约 \(-3.70\)。\(\alpha = 0.5\) 只把 B8 上最近若干次备份留在表里，这一截轨迹里小剂量的最近目标偏高，argmax 被带过去。部署后的策略很少走到 B8，所以这条分歧几乎不改变 500 条评估轨迹的平均回报。
